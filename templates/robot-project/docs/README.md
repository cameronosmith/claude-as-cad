# Notes

- `pitfalls.md` — traps that already cost time. Read before generating anything.
- `DESIGN_INDEX.md` — every canonical design, its generator, and where its notes live.
- Cross-cutting topics (servos, fasteners, fiducials, printer fits, ...) get their own file here,
  e.g. `servos.md`.
- Build-specific notes live next to the build: `builds/<category>/NOTES.md`.
- Repeatable procedures belong in skills or recipes, not notes. A procedure you'd copy-paste
  twice is a skill; a fact is a note.
